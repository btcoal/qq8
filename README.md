# qq8

Static publication site for [qqeight.com](https://www.qqeight.com), hosted on GitHub Pages.

## Structure

- `index.html` — `qq8` publication front page (`/`)
- `/<slug>/index.html` — published articles and reports (with article assets in `/<slug>/images/`)
- `404.html` — custom not-found page
- `CNAME` — custom domain configuration (`www.qqeight.com`)
- `.nojekyll` — disables Jekyll processing on GitHub Pages
- `.agents/skills/qq8-editorial/` — `qq8` editorial, design, and verification skill for agents
